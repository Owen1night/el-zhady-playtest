These are **owner instructions**, not a deployment already performed. No merge is required. The draft remains open. No migration, Supabase setting or Cron action is needed for this frontend/video update. Both hosted databases and Room A remain untouched.

1. Open [draft PR #1](https://github.com/Owen1night/el-zhady-playtest/pull/1). Record the final full commit SHA reported in the PR and check its green **Check website foundation** result. Do not substitute an earlier commit's result.
2. Open [Deploy isolated playtest](https://github.com/Owen1night/el-zhady-playtest/actions/workflows/pages.yml) in **Owen1night/el-zhady-playtest**. This is `.github/workflows/pages.yml`, not the production repository.
3. Click **Run workflow**. Under **Use workflow from**, select **codex/solo-practice-and-archive-media**. Confirm that the branch's latest commit is the reviewed final SHA, then click the green **Run workflow** button. Do not click Merge in the PR. Do not change the already configured playtest variables.
4. **Wait:** open the new run and confirm its commit is the reviewed SHA. Wait for both **build** and **deploy**, including the final `node scripts/pages-health.mjs verify` step, to finish successfully. This existing workflow builds the frontend, deploys Pages and verifies actual HTTPS assets against the built hashes. It does not execute migrations or access database tables. A green build alone is insufficient.
5. **Verify the public revision:** open `https://owen1night.github.io/el-zhady-playtest/deployment.json?release=FULL_SHA` (replace FULL_SHA with the full reviewed SHA). Expect `{"commit":"FULL_SHA"}` with the same value. The Actions summary should confirm HTTP 200 and SHA-256 matches for all published HTML/assets/fonts/licences/marker files. If the run fails or the marker differs, stop there and report that run; do not rerun SQL.
6. Open [Бейнебөлім](https://owen1night.github.io/el-zhady-playtest/#/videos) on laptop and physical iPhone Safari, reloading an old tab. Expect **three core videos** (wartime participation, wartime culture, postwar 1946), then **Алаш** under historical background. The separate AI/street interviews are not counted here.
7. On each of the four cards, tap **Осы бетте ашу**, then the real YouTube play button. Check inline playback/audio only after play, pause/fullscreen/return, and the always-visible **YouTube-де ашу** fallback. Confirm the fallback opens the matching original video. If embedding is restricted, expect a Kazakh explanation/retry and use the original YouTube link. Check captions offered by the provider. Record any device/country/account restriction; browser fixtures cannot verify that.
